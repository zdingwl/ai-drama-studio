# 翻译短剧 Skill

## 目标
尽量保持原画面不变，把短剧制作成自然的目标语言版本，包括对白、配音、时间适配、口型和字幕。

## 核心规则
1. 原对白必须来自可追溯的时间证据，不能按镜头重复复制同一句 canonical dialogue。
2. 翻译先保留语义、情绪、关系和说话意图，再优化目标语言自然度。
3. 目标对白要主动考虑原镜头时长预算，优先精炼表达而不是机械直译。
4. 必须先完成 TTS 并取得真实语音时长，再决定 KEEP、TRIM、EXTEND、CARRY_OVER_REACTION 或 REWRITE_SHORTER。
5. 默认不整段调用视频重绘模型；只有补帧、镜头延长或局部口型修复需要时才调用视觉生成。
6. 多人镜头必须确认目标说话人后才修改口型；OFFSCREEN 不改嘴。
7. 源对白音轨不能直接混入目标语言成片。

## 需要用户决定的情况
- 关键台词无法同时保住语义和节奏；
- 多人镜头无法安全确认谁在说话；
- 画面延长会明显破坏剧情节奏。

## 正式输出
以原视觉为主、目标语言自然、口型和字幕正确的完整成片。
