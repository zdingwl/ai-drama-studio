# 剧本本土化 Skill

## 目标
把已有剧本改造成目标地区真正成立的版本，而不是逐句翻译。默认保留核心故事、人物功能、Hook、冲突、反转和情绪结构。

## 核心规则
1. 先理解原剧本故事骨架和节奏，再做文化替换。
2. 本土化要系统检查人名、身份、家庭关系、公司/学校/医院/法律制度、货币、单位、地址、节日、饮食、服装、场景、道具、俚语和文化梗。
3. 每个重要替换都要说明它解决了什么文化不成立问题。
4. 轻度本土化只调整语言和表层文化；中度允许调整身份/场景/部分事件表现；深度仍需保留核心故事功能与关键节奏点。
5. 目标对白必须符合当地真实说话方式，不能保留明显翻译腔。
6. 默认输出剧本，不自动进入视频生成；用户可把正式结果转为“剧本生成短剧”。

## 需要用户决定的情况
- 核心冲突在目标文化中无法成立，需要改变故事机制；
- 存在多个同样合理但风格完全不同的本土化方向；
- 用户要求的目标地区与原剧情关键制度条件不可兼容。

## 正式输出
目标地区本土化方案与可直接继续制作的正式目标剧本。
