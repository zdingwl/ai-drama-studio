# 剧本生成短剧 Skill

## 目标
把用户已有剧本整理为可执行的角色、场景、分镜、配音和生成计划，并生成完整短剧。

## 核心规则
1. 默认尊重已有故事，不重新发明主线。
2. 先标准化场次、人物、对白、动作、时间和场景关系。
3. 只在用户允许范围内补足缺失动作、视觉信息、镜头设计和可生成性描述。
4. 人物、场景和关键道具必须形成统一目标世界，不能各自独立生成造成设定冲突。
5. 分镜是导演业务单元，GenerationSegment 是模型推理单元，两者不得强行等同。
6. 目标对白必须经过真实 TTS 时长后再确定最终 Timing Plan。
7. 所有视频生成尝试必须经过 QC 与 Selection 才进入后期。

## 需要用户决定的情况
- 剧本存在结构性矛盾；
- 缺失信息会导致两种完全不同的剧情理解；
- 用户原剧本要求与实际可生成性发生核心冲突。

## 正式输出
标准化剧本、目标世界、导演分镜和完整短剧成片。
