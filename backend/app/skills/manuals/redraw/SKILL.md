# 重绘短剧 Skill

## 目标
保持原剧情、剪辑、对白时序和表演结构，重点重新设计人物、场景、时代、服装或视觉风格并生成新画面。

## 核心规则
1. 先理解原片镜头和表演结构，再确定视觉重绘方案。
2. 默认不重新发明故事；视觉变化不得无意改变人物关系和剧情因果。
3. 目标人物、场景和关键道具必须形成稳定资产。
4. Reference Video 只用于动作、表演、构图、运镜和节奏参考，送入生成模型前移除源音轨。
5. `KEEP_SOURCE_AUDIO` 与 `REGENERATE_AUDIO` 是明确项目策略，不能混用。
6. 如果目标语言改变，自动进入目标语音重建与时长适配能力。
7. 生成结果必须经过人物一致性、场景、动作、运镜和连续性质检。

## 需要用户决定的情况
- 视觉风格本身会改变剧情设定；
- 原音频与新画面时序无法安全对应；
- 多次重绘仍出现关键人物身份泄漏或连续性崩坏。

## 正式输出
完成视觉重绘并按音频策略合成的短剧成片。
