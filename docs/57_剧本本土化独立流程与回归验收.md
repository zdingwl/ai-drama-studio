# 剧本本土化：独立工作流与验收门禁（初稿）

## 状态

本文件是下一阶段的工程合同，不表示剧本本土化已可用。完成真实运行和人工验收前，`SCRIPT_ANALYSIS` 与 `EXPORT_SCRIPT` 不得标为 `AVAILABLE`。

## 权威约束

- 仅 `SCRIPT_LOCALIZATION` 可进入新工作流；严禁放宽 Replica 的 `_assert_replica` 等业务门禁。
- 当前 `SOURCE_TEXT` 上传与原文不可变存储直接复用，保留原始版本、SHA256、字符数；新的结果仅写入独立文本项目的 Artifact/revision，不反写 Source。
- 采用独立的 typed 数据契约、Service、API、Task runner、ProviderJob；保留原有 Replica P11/P12 及五步产品主链不变。
- 不要把 `SOURCE_TEXT_SNAPSHOT` 写成 Replica 专属 `SOURCE_VIDEO_SNAPSHOT`；不能直接复用视频语音字段/视频 Episode 模型。
- 任务需要显式 POST；所有 GET 只读；远端调用之前先持久化 ProviderJob；使用当前 source revision/fingerprint 并在发布前再次检查，失败不覆盖旧 CURRENT。
- 新文档输入使本项目下游 Artifact 递归 STALE，不得跨项目级联失效。
- 新流程的 `TARGET_SCRIPT` 是完整可读剧本文本，不得直接写入 `ReplicaTargetScriptRevision` 的逐句带时间戳 schema。允许共用枚举类型，不共用不兼容 typed 表。

## 用户流程

上传/粘贴原剧本 → 查看原剧本 → 点击「分析剧本」→ 查看人物/场景/故事骨架及不确定项 → 点击「生成本土化方案」→ 审阅术语映射和需决策项 → 点击「生成本土化剧本」→ 原文/目标文逐段对照与人工修订 → 导出 Markdown/TXT。

首版只支持 TXT/MD；粘贴内容经过与文件上传相同的文本持久化入口。DOCX/PDF 不在首版承诺范围，避免把解析失败默认为空或自动 OCR。

## 长文本

按段落和场景优先稳定切块；块带全局序号及 source spans。先全局理解人物/剧情，再输出全剧唯一角色、地点、机构、术语映射；每块必须使用同一映射，生成后按原顺序拼接并做跨块一致性检查。超过模型上下文的内容必须分批执行，禁止截断后声称已分析全文。

## 完成标准（必须有自动测试）

1. `REPLICA` 五步路由、导航、现有 P11/P12 API 的正常/拒绝行为不变；现有 Replica 专项测试仍通过。
2. `SCRIPT_LOCALIZATION` 文本上传与重新上传、UTF-8、空文档、非法项目类型、GET 只读均通过。
3. 分析结果 Source 文本不变；人物/场景/对白不丢；不确定信息单独暴露。
4. 方案与目标剧本严格绑定 CURRENT 来源、目标语言/地区和 Skill 版本；过期输入阻断发布。
5. 文化替换显式记录 change log；不能保持原剧情成立的修改进入人工决策而非自动落地。
6. 目标文本可编辑、产生独立 revision、可导出；导出内容与所选 CURRENT revision 一致。
7. Provider 未配置、超时、无效 JSON、任务取消、重复提交及重试均安全失败，不伪造成功。
8. 未运行真实模型与用户复核前只记录工程完成状态，不能宣称真实本土化质量 PASS。

## 核验资料（官方）

- Microsoft Globalization《Localize your product》：https://learn.microsoft.com/en-us/globalization/localization/localization-overview —— 本地化涉及文化引用、习语、货币、日期、单位和一致性资产；这是通用本地化工程资料，不应当作影视剧本规范。
- Microsoft《How to perform localization testing》：https://learn.microsoft.com/en-us/globalization/testing/how-to-perform-localization-testing —— 质量维度包括准确度、语境、风格、术语、一致性和目标文化适配。
- Final Draft《Screenplay Formatting and Elements》：https://www.finaldraft.com/learn/screenplay-formatting-elements/ —— 场景标题、动作、人物及对白应按不同剧本元素保存。
- Final Draft《How to Format a Screenplay》：https://www.finaldraft.com/learn/how-to-format-a-screenplay/ —— Scene Heading、Action、Dialogue、Parenthetical、V.O./O.S. 的结构边界。

上述来源证明基础格式和通用本地化测试原则；“故事锁定、映射注册表、按块覆盖率”等为本项目自定义工程契约，不能冒称官方行业标准。
