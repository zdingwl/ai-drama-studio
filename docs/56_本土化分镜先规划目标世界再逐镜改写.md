# 本土化分镜：先规划目标世界，再逐镜改写

> 日期：2026-09-19。补充 docs/55，并替代其中“首次出现的实体只冻结名称”的不足实现。五步主流程不变，不恢复旧 P11/P12 前置。

## 问题与目标

真实美国英语项目出现同一人物不同英文姓名、家庭姓氏、房号及住宅类型漂移。仅把原片画面换名称、对白译成英文，不能完成重新拍摄所需的本土化设计。

## 内部执行顺序

1. 只读 CURRENT SOURCE_VIDEO_SNAPSHOT 和目标语言、地区、风格配置。
2. 同一 Task 先读取全部剧集的分镜和对白，规划统一目标世界：人物姓名、身份关系、外形服装；场景位置、空间关系、装修；道具外观、货币和文化表达。输出中文总体设定、连续性规则及完整实体定义。
3. 规划结果验证完整实体覆盖并持久化 checkpoint。每次远端调用前持久化独立 ProviderJob。
4. 所有镜头批次读取完整冻结规划。批次只编写镜头和对白，不再设计或覆盖实体；服务端确定性绑定规划中的实体定义。
5. 合并候选保留总体设定与实体定义，供普通页面审核。恢复任务复用已验证规划和批次，输入或合同变化必须拒绝复用。

## 本土化范围

必须重新设计目标人物与场景，不能默认沿用原片演员外形、原姓氏或家具装修。目标语言不等于族裔；不得自动将美国英语强制为白人，也不得仅因原片中国人物而默认整部剧为华裔移民故事。人物背景应在目标世界中明确且一致。

保留故事功能、关系、冲突顺序、动作逻辑、镜头数量、权威时间及结构化摄影事实。原片画面仅作为剧情与构图依据，不能充当目标视觉身份。家庭成员、房间与地址、称谓、金额在规划、画面、道具和对白中必须一致。文化替换保留原事件的成立条件，不增加剧情。

## 发布与兼容

旧正式结果保持可读，不自动重写或伪造验收。新候选须显式人工确认才发布。视觉变化使旧资产、提示词和视频沿 Artifact Graph 失效；不自动生成图片或视频。GET 仍零写入。

新增总体设定字段对历史 JSON 使用空默认值，旧结果不因此被标为已完成世界规划。新合同必须校验非空规划。工程测试与真实 Provider 执行不能代替人工质量确认。


## 目标时长重规划补充（2026-09-19）

本土化分镜的原片 `start/end/duration` 只作为 Source Truth 与镜头锚点参考，不能再作为目标成片的强制时长。每个本土化镜头必须规划 `target_duration_ms`，服务端按镜头顺序建立目标时间轴；因此目标镜头和整集时长可随目标语言自然语速、表演停顿、动作与重新设计的场景调度变长或变短。

原片时间、对白原始 overlap 与镜头顺序必须独立保留以便追溯。目标对白的可说时长按重规划后的目标 overlap 校验，不能再按原片时间窗强迫压缩。H3 与后续生成只消费目标时间轴。


### 时长不足的确定性补足

Provider 给出的目标时长是创作提案。若目标对白按该提案仍无法自然说完，服务端必须优先扩展关联的目标镜头，不能再把对白压回原片时长，也不应把可计算的时长补足反复交给远端重试。单镜超过 15 秒才 fail closed。
