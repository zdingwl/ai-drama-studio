# 4. 人工裁决验收口径

P9 支持：

```text
CONFIRM
MERGE
SPLIT
MARK_UNKNOWN
REASSIGN
```

最终真实项目没有为了“证明按钮可用”而故意把已经正确的 Character / Scene / Prop truth 做错误 merge/split。真实验收使用了不会破坏正确 Source Truth 的 Speaker `CONFIRM` 恢复路径；MERGE / SPLIT / MARK_UNKNOWN / REASSIGN 的 partition、CURRENT 输入校验、成员重算、Speaker→Character link 校验与 revision 规则继续由自动 contract / composition tests 覆盖。

因此人工验收规则明确为：

- 真实素材存在真实歧义时，应实际执行相应 MERGE / SPLIT / REASSIGN；
- 真实素材没有歧义时，不要求人为制造错误 Source Truth；
- 至少一条真实人工 adjudication revision 路径必须完成；
- 所有 destructive / topology-changing operation 必须有自动化 fail-closed 测试。

本项目满足该口径。
