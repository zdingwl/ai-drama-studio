## 7.1 28 Shot 最终音画人工验收方法

对 28 个 Shot 逐个播放 **Reference Clip + 对应完整 Episode 原片区间**。Reference Clip 只是精看入口，判断仍以完整 Episode 为 Source Truth。

每个 Shot 至少核对：

- Shot 边界：画面切点是否与 P5 对应；
- 画面描述：主体、动作、空间关系、事件是否忠于原片；
- 景别：特写 / 近景 / 中景 / 全景等是否合理；
- 构图：主体位置、前后景、遮挡关系是否合理；
- 角度 / 镜头类型：正反打、主观 / 客观、俯仰、过肩等是否与画面一致；
- 运镜：固定、推拉、摇移、跟拍等是否真实存在；
- 焦距 / 景深描述：不得把模型推测当成确定器材参数；
- 人物绑定：只核对 P7 candidate 是否对应画面人物，不在 P8 做最终身份归一；
- 场景绑定：是否对应 P7 场景候选；
- 道具绑定：是否真的在镜头中出现 / 有关；
- 对白正文：必须和听到的原片及 P6 canonical 一致；
- delivery：DIALOGUE / VOICEOVER / OFFSCREEN / UNKNOWN 是否符合听觉与画面；
- 音效 / 环境声：不得无中生有，也不能漏掉显著声音事件；
- 用户可读性：该 Shot 行是否足够清楚地支持后续复刻 / 重绘 / 翻译制作。

## 7.3 P8 PASS / FAIL 判定

可判定 P8 最终 PASS 的前提：

- 28/28 Shot 都完成实际音画核对；
- 没有系统性 Shot 边界错误；
- 没有系统性人物 / 场景 / 道具错绑；
- 没有会误导后续制作的画面 / 镜头语言错误；

- residual ASR 问题数量有限且不破坏后续制作，或已明确记录为后续通用 P6 Provider 质量优化项。

以下任一情况应 FAIL 并回到对应上游，不允许在 P8 里补丁式修正：

- 大量 canonical ASR 与原音不符 → 回 P6；
- SOURCE_BIBLE 全局人物 / 剧情 / 场景理解错误 → 回 P7；
- Shot 时间边界系统性错误 → 回 P5；
- P8 自身视觉描述 / camera / candidate binding 大面积不符 → 回 P8。
