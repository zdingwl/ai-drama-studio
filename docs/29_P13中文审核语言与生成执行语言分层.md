# P13 中文审核语言与生成执行语言分层

> 日期：2026-09-11  
> 状态：**P13 contract amendment；高于 docs/28 中未明确审核语言的旧口径。**  
> 前置事实：P12 已 PASS；P13 工程已实现但尚未真实人工 PASS；`TARGET_ASSETS = PLANNED`。  
> 范围：只调整 P13 Target Assets 的用户审核语言与未来生成执行语言边界，不修改 P11/P12 已验收 Artifact，不进入 P14+。

---

## 1. 触发问题

真实产品验收页面显示：目标资产的人物、场景、道具视觉设计正文大量使用英文。虽然项目目标地区是美国、目标语言是 English (US)，但当前产品主要由中文用户操作；P13 这些文本首先用于**理解、审核与修改视觉资产约束**，不是直接给最终美国观众阅读，也不是已经提交给图像/视频模型的最终 prompt。

因此需要严格区分：

```text
用户审核语言
!=
目标受众成品语言
!=
未来模型执行 prompt 语言
```

---

## 2. 产品语言原则

AI Drama Studio 当前中文产品界面采用：

```text
用户界面 / 审核 / 解释 / 约束 = 中文优先
目标受众最终对白            = target_language
未来图像/视频模型执行 prompt = generation adapter 按模型能力决定
```

P13 v1.1 的正式审核语言固定为：

```text
review_language = zh-CN
```

即使项目配置为：

```text
target_language = en-US
target_region   = US
```

P13 Provider 返回给用户审核的视觉设计正文仍必须使用简体中文。

---

## 3. 哪些内容必须中文

以下 P13 review-facing 语义必须以简体中文表达：

### Character

```text
demographic_direction
face_direction
hair_direction
body_direction
wardrobe_baseline
signature_visual_features[]
continuity_constraints[]
generation_guidance[]
negative_constraints[]
```

### Scene

```text
layout
architecture_style
interior_exterior_style
materials_palette[]
fixed_landmarks[]
lighting_baseline
time_of_day_baseline
continuity_constraints[]
generation_guidance[]
negative_constraints[]
```

### Prop

```text
visual_form
materials[]
color_palette[]
scale_reference
signature_visual_features[]
continuity_constraints[]
generation_guidance[]
negative_constraints[]
```

服务端从 Target Bible 确定性注入的 `identity_direction / spatial_identity / functional_identity` 保持 P11 semantic truth 原值，不由 P13 Provider 翻译或改写。

---

## 4. 哪些内容可以保留目标地区写法

中文审核正文中允许并鼓励保留无法自然翻译或翻译后反而降低准确性的目标地区实体，例如：

```text
Lila Xu
Jake Miller
Austin
HEB
iPhone
$19.99
unit 502 / 503
品牌、型号、专有名词、目标地区地址/机构名
```

规则是：

> **解释用中文，实体名按目标地区真实写法保留。**

不能为了“全中文”把目标世界的人名、品牌、货币、型号改回 Source 世界，也不能改变 P11 已确认的 Target identity。

---

## 5. P13 Provider 语言门禁

P13 Prompt 升级为：

```text
P13_PROMPT_VERSION = p13-replica-target-assets-v2
```

Professional Skill 升级为：

```text
replica-target-assets@1.1.0
```

Provider 必须明确收到：

1. `review_language = zh-CN`；
2. 所有 review-facing 视觉描述与约束使用简体中文；
3. 人名、地名、品牌、型号、货币、目标地区专有实体可保留原文；
4. 不要因为目标语言是英语就把审核文本整体写成英文；
5. 当前 `generation_guidance` 仍是给中国用户审核的设计指导，不等于最终英文生成 prompt。

服务端在 Provider typed parse 后增加审核语言校验。若主要 review-facing 字段没有中文表达，应 fail closed：

```text
P13_PROVIDER_REVIEW_LANGUAGE_INVALID
```

不得把全英文候选发布给用户继续审核。

---

## 6. 未来生成执行语言

本次**不实现 P14 / 图像生成 / 视频生成**。

未来真正调用图像/视频 Provider 时，应由独立 generation adapter 读取已确认 `TARGET_ASSETS`，再根据模型能力生成执行 prompt：

```text
CURRENT TARGET_ASSETS（中文可审计视觉约束）
        ↓
Generation Adapter
        ↓
model-optimized execution prompt
        ↓
Image / Video Provider
```

执行 prompt 可以是英文，也可以是模型更适合的其他语言；它属于 Provider adapter/runtime，不应反过来要求 P13 用户审核正文全部使用英文。

禁止现在为了“以后可能需要英文 prompt”提前把 P13 用户审核数据做成英文墙。

---

## 7. 旧候选处理

本次语言合同升级后，历史尚未确认的：

```text
review_status = NEEDS_REVIEW
```

P13 候选基于旧 `p13-replica-target-assets-v1` Prompt，不再满足当前中文审核合同。

迁移规则：

```text
旧 NEEDS_REVIEW candidate
→ SUPERSEDED
```

只 supersede 尚未确认候选：

- 不删除历史 candidate；
- 不伪造 REJECT；
- 不修改已 ACCEPTED / REJECTED / SUPERSEDED 历史状态；
- 不自动创建新 Task；
- 页面刷新仍只读；
- 用户显式点击重新生成后，才调用新 v2 Provider 生成中文候选。

若工程环境中存在正式 CURRENT TARGET_ASSETS，不因本语言升级自动重写其内容；正式资产是否需要新 revision 必须由用户显式 regenerate + review 决定。

---

## 8. UI 文案

目标资产工作区必须明确告诉用户：

```text
资产说明与审核内容默认使用中文；人物名、地名、品牌等保留目标地区写法。
真正进入图片/视频生成时，系统会再按生成模型需要整理执行提示，不要求用户阅读英文 prompt。
```

普通 UI 不展示 `ProviderJob / fingerprint / prompt_version` 等工程术语。
