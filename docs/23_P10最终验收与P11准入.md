# 5. P11 正式准入范围

下一工程切片正式进入：

```text

```

但“准入”只表示可以开始 P11 的**规划、Professional Skill / typed schema / Artifact / revision / fingerprint / provenance / guardrail / API / UI / 验收设计与实现**，不代表任何 Target 能力已经 AVAILABLE。

P11 开发前必须先建立新的正式契约，至少明确：

```text
CURRENT SOURCE_VIDEO_SNAPSHOT
→ Replica preservation locks
→ localization decisions
→ TARGET_BIBLE / equivalent typed Target artifact
```

必须继承 Replica 硬规则：

- 故事不乱改，节奏不重做，文化和表达才本土化；
- 默认锁定 Hook、冲突、反转、信息揭示顺序、情绪峰值、Payoff、Cliffhanger；
- 默认锁定 Story Beat timing 与 Shot rhythm baseline；
- Source Facts 不得被 Target 创作反写；
- Target 人物 / 场景 / 道具 /对白属于 Target namespace，不得冒充 Source identity；
- P11 不得提前实现正式 Target Storyboard、TTS Timing 或 Generation；这些属于后续工程切片。

# 6. P11 硬输入边界

P11 的正式 Source 输入必须以：

```text
CURRENT SOURCE_VIDEO_SNAPSHOT
```

作为下游版本边界，而不是重新从散落的 P5~P9 Artifact 自行拼装“当前事实”。

需要查看细节时，可以沿 Snapshot lineage 读取被冻结的 Source Artifact，但必须保持：

```text

```

Source Snapshot STALE 时，基于旧 Snapshot 的 Target Bible 必须能够正确进入 STALE / blocked 状态；不得继续把旧 Source 世界当 CURRENT 使用。
