当前 Workflow V2 审核文档记录的测试项目实例：


这里的 `54 → 76` 只是**当前测试项目实例**，不是系统固定规则。

系统通用规则永远是：

```text
N 条完整对白
→ M 个 ShotDialogueProjection
```

一条完整对白可以跨多个 Shot，但不能因此复制成多条独立业务对白。

## 8. 更新规则

每次完成一个重要开发阶段，只更新真实事实：

- 已实现什么；
- 哪些测试通过；
- 哪些本地 Runtime 真正测试过；
- 当前测试项目卡在哪里；
- 下一步唯一优先事项是什么。

禁止把“计划要做”“代码存在”“测试 mock 通过”“真实模型跑通”“用户验收通过”写成同一种完成状态。
