# 3. Qwen3.8 代码迁移结果

当前已经建立正式业务 Provider：

```text
SourceVideoUnderstandingProvider
  └─ Qwen38VideoUnderstandingProvider
       model: Qwen/Qwen3.8-27B
       provider: qwen38-video-understanding
       profile: source-video-understanding-qwen38-v1
```

当前默认 P2：

```text
ASR
→ OCR
→ Qwen38VideoUnderstandingProvider
→ deterministic Fusion
→ current source facts
→ Auto Snapshot V2
```

Qwen3.8 继续复用已经验收过的 Fast Grounded 视觉策略：

```text
Episode/Window context
  只提供保守的 scene / continuity 上下文

Exact frozen Shot frames
  继续作为 Shot 视觉事实主证据
```

没有为了迁移模型重写 Shot / Timeline / Snapshot schema。

## Canonical dialogue 硬边界

Qwen3.8 只负责视觉/剧情事实：

- 场景；
- 人物外观与可见行为；
- 动作/表情/姿态/视线/互动；
- 道具；
- 景别/机位/构图/运镜/光线；
- continuity / narrative context。

它**不能**：

- 改写 ASR/OCR canonical source dialogue；
- 把模型自己听到/看到的文本升级成 canonical dialogue；
- 写入 Target-side dialogue/character/scene 数据；
- 直接创建 Final Character/Scene/Prop 业务 ID。

视觉 semantic normalizer 继续采用白名单，因此模型即使返回 `source_dialogue`、`canonical_dialogue`、`target_dialogue` 等字段，也不会进入正式 VLM Evidence。

# 4. Qwen3.8 Runtime 兼容迁移

旧 Qwen runner 使用历史 `Qwen3VLForConditionalGeneration` 加载入口；Qwen3.8 当前本地加载使用 multimodal auto-model seam。

因此新增：

- `scripts/run_breakdown_vlm_fast_grounded_qwen38.py`
- `scripts/check_qwen38_visual_runtime.ps1`

专用 runner 只替换模型加载 seam，保留现有 Fast Grounded prompt / window / exact-shot / timing 逻辑。

readiness 检查覆盖：

- isolated Python；
- PyTorch/CUDA；
- `AutoModelForMultimodalLM`；
- `AutoProcessor`；
- `qwen_vl_utils`；
- Qwen3.8 checkpoint `config.json`；
- 专用 runner CLI import。

**readiness 通过仍不等于真实视频验收。**

本机检查命令：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/check_qwen38_visual_runtime.ps1
```

真实 Episode 仍必须通过正式 P2 路径执行并记录耗时/VRAM/RAM/失败率。

# 7. SourceDramaSnapshot / Source Screenplay 硬边界

## SourceDramaSnapshot

继续是下游唯一正式 Source 事实入口：

- canonical dialogue exact-once；
- SourceDialogueUtterance → ShotDialogueProjection 保持 1:N；
- Speaker current binding 唯一；
- Directing facts 不丢；
- source revision/fingerprint 改变后下游正确 STALE。

## Source Screenplay V2

继续保持：

- SourceDramaSnapshot 不可变；
- Episode Understanding 参与动作组织；
- canonical dialogue 不由 screenplay model 生成；
- 每条 canonical dialogue 恰好插入一次；
- GET 只读 materialized artifact；
- compile 必须显式 POST/task。

Qwen3.8 + D-ORCA 的目标是提高它的上游事实质量，不是推倒重写它。
