# 3. v3 真实验收后锁定的质量边界

P13 最终 PASS 后，下列规则成为正式长期边界：

1. `Target Bible = semantic truth`，`Target Assets = visual realization`；
2. review-facing 内容中文优先，目标地区专有实体可保留原文；
3. `continuity_constraints / generation_guidance / negative_constraints` 只描述当前 asset 的视觉稳定性；
4. Story Beat / shot order / dialogue / rhythm / cliffhanger / relationship 等上游 preservation locks 不机械复制进每个 asset packet；
5. Character `wardrobe_baseline` 是基础服装身份，不自行建立逐 Scene / Shot 换装计划；
6. Scene `time_of_day_baseline` 是视觉基线，不根据 Scene 顺序、闪回或情绪发明剧情时间变化；
7. 当前 text-only Provider 不生成真实参考图，`reference_media=[]` 时不得伪造 URI、hash、尺寸或远端图片任务；
8. Provider succeeded 只产生 `NEEDS_REVIEW` candidate；只有用户显式 ACCEPT 才发布正式 CURRENT `TARGET_ASSETS`；
9. REJECT / Provider failure / partial failure 不覆盖旧 CURRENT；
10. `TARGET_BIBLE --DERIVED_FROM--> TARGET_ASSETS`，Target Bible 新 revision 会使旧 Target Assets 正确 STALE；
11. `TARGET_SCRIPT` 不是 P13 输入，因此 Target Script revision 变化不得无依据地 stale 视觉资产；
12. GET 继续只读；生成、重生成、ACCEPT、REJECT 都必须是显式 Command；
13. P13 不创建 Target Voice / TTS / Timing / Storyboard / Video Generation / QC / Lip Sync / Post Artifact。

旧 `replica-target-visual-identity-v1` 正式 revision 继续保留为历史，不由 migration 静默改写；最终可用 P13 基线以 v3 / visual-identity-v2 为准。

# 5. P14 准入评估

Root Replica Skill 在 `target_assets` 后的下一个内部步骤当前是：

```text
voice_timing
```

现有 Root Skill 对这一内部步骤的声明是：

```text
requires:
- TARGET_SCRIPT

capabilities:
- TTS
- TIMING

produces:
- TARGET_AUDIO
- TIMING_PLAN
```

这只说明 Root Skill 的长期顺序，不等于 P14 已经有正式 Professional Skill / typed contract / Provider contract / 人工验收规范。

因此本次 P13 PASS 后的准入结论是：

```text
P13 = CLOSED / PASS
TARGET_ASSETS = AVAILABLE
P14 implementation = NOT STARTED
P14 formal contract = REQUIRED BEFORE IMPLEMENTATION
```

下一工程切片可围绕 **Target Voice / TTS + Timing** 进行正式合同设计，但必须先建立独立编号文档并明确至少以下内容后才能编码：

1. P14 的正式名称、职责边界与是否将 TTS / Timing 拆分为一个或多个工程阶段；
2. 正式硬输入，至少需要评估 CURRENT `TARGET_SCRIPT` 与 speaker / target identity 的依赖；
3. `TARGET_AUDIO` typed schema、speaker / voice binding、真实音频媒体与 ProviderJob provenance；
4. Actual Speech Duration 的权威来源与单位；
5. `TIMING_PLAN` typed schema，以及何时允许最小节奏适配；
6. Source rhythm preservation 与目标语音真实时长冲突时的裁决规则；
7. Artifact Graph、revision / fingerprint / CURRENT / STALE；
8. ProviderJob-before-remote、retry / resume / idempotency；
9. 人工听审 / 质量验收入口；
10. 明确不得提前进入 Target Storyboard / Video Generation / QC / Lip Sync / Post。

在新的 P14 正式合同出现前，不得因为 P13 PASS 顺手把 `TTS / TIMING` 标成 AVAILABLE，也不得实现后续 Generation 链。
