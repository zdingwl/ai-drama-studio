```text

= Source Truth
```

视频类项目内部编排：

```text
完整 Episode
        │
        ↓
Media Preflight
        │
        ├────────────────┬────────────────┐
        ↓                ↓                ↓
Shot Anchors         ASR Evidence      OCR Evidence
        │                │                │
        └────────────┬───┴────────────────┘
                     ↓
              Source Evidence / P6
                     +
               完整 Episode
                     ↓
          整集多模态原片理解 / P7
                     ↓
      SOURCE_BIBLE / Story / Rhythm
                     +
             Shot Anchors
                     ↓
          逐镜精细拉片 / P8
                     ↓
          SOURCE_SHOT_FACTS
```

硬规则：

- Shot Boundary 读取完整 `SOURCE_VIDEO`；
- P6 ASR 读取完整连续音轨，不能按 Shot / Reference Clip 分开识别；
- P6 OCR 扫描完整视频时间轴，Shot Anchors 只能辅助抽帧 / 去重；
- P6 Source Evidence 与 P7 Source Understanding 严格分离；
- P7 必须读取完整 Episode，不允许把每个 Shot 独立丢给模型猜剧情后再拼接；
- P7 对白 / OCR 的文字事实必须引用 CURRENT P6 Evidence；模型不得覆盖 canonical Source Evidence；
- P8 必须读取完整 Episode + CURRENT SOURCE_BIBLE + CURRENT SHOT_ANCHORS + CURRENT P6 canonical Evidence；
- P8 Shot 时间只认 P5；对白正文只认 P6；人物 / 场景 / 道具只能绑定 P7 candidate；
- P8 不得为了修正 ASR 质量自行重新听写。

# P6 当前基线：Canonical Evidence v2

旧 P6 v1 的真实样例曾出现：

```text
50 raw ASR segments
→ 激进相邻合并
→ 8 canonical utterances
```

最终 P8 人工检查确认其中存在多轮不同说话回合被串为一个 canonical utterance 的情况，导致 P8 虽然严格遵守 P6 正文，却把同一超长正文 overlap 到多个 Shot。

当前正式整改：

```text
p6-source-evidence-v2
segment-preserving-dialogue-v2
```

策略：

- 完整 Episode 连续 ASR 架构不变；
- raw ASR segment 默认保持 canonical 边界；
- 仅有明确 continuation 标点、短时间 gap、语言兼容且总时长受限时允许合并；
- 不再仅凭“相邻 segment 很近”跨段合并；
- 默认 faster-whisper 模型升级为 `large-v3-turbo`；
- VAD 使用 500ms minimum silence；
- 不使用真实样例专用硬编码纠错词表；
- Provider profile / canonical policy 进入 fingerprint / provenance；
- 显式 P6 rerun 在已有正式 Evidence revision 后必须创建新 Task / revision，同轮重复提交仍去重。

迁移：

```text
0012_p6_canonical_evidence_v2
```

升级后保留全部历史，但自动失效：

```text
旧 SourceEvidenceSet current flag
旧 SOURCE_DIALOGUE
旧 SOURCE_BIBLE
旧 STORY_SKELETON
旧 RHYTHM_SKELETON
旧 SOURCE_SHOT_FACTS
受影响 ProjectExecutionPlan
```

SOURCE_VIDEO 与 SHOT_ANCHORS 不失效。

正确恢复链：

```text
P6 v2 真实重跑
→ 新 CURRENT SOURCE_DIALOGUE
→ P7 重跑
→ 新 CURRENT SOURCE_BIBLE / Story / Rhythm
→ P8 重跑
→ 新 CURRENT SOURCE_SHOT_FACTS
→ 28 Shot 最终音画人工验收
```
