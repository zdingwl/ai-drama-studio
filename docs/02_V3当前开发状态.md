# Source Understanding 当前架构

完整 Episode 永远是 Source Truth：

```text
SOURCE_VIDEO / 完整 Episode
= Source Truth
```

当前已完成工程链：

```text
完整 Episode
        │
        ↓
Media Preflight
        │
        ├────────────────┬────────────────┐
        ↓                ↓                ↓
Shot Anchors         ASR Evidence      OCR Evidence
        │                │                │
        └────────────┬───┴────────────────┘
                     ↓
              Source Evidence / P6
                     +
               完整 Episode
                     ↓
          整集多模态原片理解 / P7
                     ↓
      SOURCE_BIBLE / Story / Rhythm
                     +
             Shot Anchors
                     ↓
          逐镜精细拉片 / P8
                     ↓
          SOURCE_SHOT_FACTS
                     +
        完整 Episode / P5 / P6 / P7
                     ↓
 Speaker / Character / Scene / Prop 最终归一 / P9
                     ↓
 SOURCE_CHARACTERS / SOURCE_SPEAKERS / SOURCE_SCENES / SOURCE_PROPS
                     ↓
          P10 SourceVideoSnapshot
             DETERMINISTIC_FREEZE
                     ↓
           SOURCE_VIDEO_SNAPSHOT
       （工程已就绪，待真实人工验收）
```

硬边界：

- P5 Shot Boundary 读取完整 `SOURCE_VIDEO`；
- P6 ASR 读取完整连续音轨，不能按 Shot / Reference Clip 分开识别；
- P6 OCR 扫描完整视频时间轴，Shot Anchors 只能辅助抽帧 / 去重；
- P6 raw ASR/OCR 永久保留，canonical 可以做严格可追溯自动裁决和显式人工裁决；
- P7/P8/P9/P10 无权静默改写 P6 canonical dialogue / OCR；
- P7 必须读取完整 Episode；
- P8 必须读取完整 Episode + CURRENT SOURCE_BIBLE + CURRENT SHOT_ANCHORS + CURRENT canonical Source Evidence；
- P8 Shot 时间只认 P5；对白正文只认 P6；人物/场景/道具只能绑定 P7 candidate；
- P8 speaker candidate 是 provisional candidate，不等于 P9 最终 Speaker Truth；
- P9 Provider 按完整 Episode / 全集批次执行，利用跨 Shot、必要时跨 Episode Evidence 做最终归一；
- P9 Speaker 与 Character 分层，Speaker→Character 可以为 null；
- P9 UNKNOWN / UNRESOLVED 是一等正式状态，不允许服务端做最高相似度兜底；
- P9 不得反向改写 P5/P6/P7/P8 历史 revision；
- P10 只冻结当前已验收 Source Facts，不调用模型、不创建 ProviderJob、不重新理解 Episode；
- P10 的 `SOURCE_SPEAKERS` 是独立正式输入和独立 Snapshot section；
- P10 必须保持 P5 Shot 时间与 P6 canonical dialogue/OCR 原值；
- P10 Snapshot 必须保存 11 类上游 Artifact 的 revision / fingerprint / provenance，并进入 Artifact Graph；
- 任一上游 CURRENT Source Artifact 变化后，旧 Snapshot 必须递归 STALE；
- P10 GET / revisions GET 只读，定稿只允许显式 POST；
- Target / Production Artifact 不得反向写入 Source Snapshot；
- P10 最终真实验收通过前不得进入 Target Localization / Target Bible 正式实现。
