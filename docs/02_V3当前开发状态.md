- P5~P10 Source Facts 不允许被 Target / Production 阶段反向改写；

只执行 **P13 Target Assets 真实 Provider + 真实项目 + 人工内容质量验收**，不进入 P14+。

真实验收至少确认：

1. 使用真实 CURRENT TARGET_BIBLE 启动 P13；
2. 真实 Provider 返回完整 Character / Scene / Prop visual identity packet；
3. ProviderJob / payload fingerprint / model / skill provenance 可追溯；
4. 候选初始必须是 `NEEDS_REVIEW`，不能自动成为正式资产；
5. 不存在伪造参考图；当前未接入已验收参考图 Provider 时 `reference_media=[]`；
6. 人物外观、场景布局、道具形态与 CURRENT Target Bible 语义一致，并具备跨镜连续性价值；
7. 同一 Target entity 的 `target_asset_id` 在 regenerate 中保持稳定；
8. 未变化视觉包 revision 不乱涨，变化视觉包只推进对应单资产 revision；
9. REJECT 后可显式 regenerate 新候选；
10. ACCEPT 后才生成 CURRENT TARGET_ASSETS，且 provenance / lineage / graph 完整；
11. Target Bible 新 revision 会使旧正式资产 STALE，旧 Bible candidate 不能发布；
12. Target Script 新 revision 不影响 TARGET_ASSETS validity；
13. 页面刷新和 GET 无副作用；
14. 没有生成 TTS / Timing / Storyboard / Video Generation / QC / Lip Sync / Post 等越界 Artifact。

只有上述真实验收通过，并由用户明确确认：
