## Root Skill / Manifest

六个 Root Skill 已迁入：

```text
skills/projects/*/manifest.json
skills/projects/*/SKILL.md
```

机器运行读取结构化 manifest，不解析 Markdown 猜业务结构。

Manifest 已包含：

- version / category；
- when_to_use / when_not_to_use；
- required_inputs；
- readable_artifacts；
- required_capabilities；
- subskills；
- steps；
- user / auto decision policy；
- output_contracts；
- completion_criteria；
- failure_policy。

Registry 启动时执行 schema 校验；非法 manifest、重复 Skill ID、重复 ProjectType、缺手册都会 fail-fast。

# P3 SourceAsset + 输入系统 ▶ 当前阶段

下一步只建设“真实输入进入正式 Artifact Graph”的能力，不提前跳到模型理解。

目标：

```text
用户原始文件
→ SourceAsset
→ SHA256 / 安全路径 / MIME / 大小
→ 视频 Episode 或文本 SourceDocument
→ 原始文件不可变
→ 正式 Source Artifact
→ 显式重新编译 ProjectExecutionPlan
```

## 视频项目

适用：

```text
REPLICA
REDRAW
TRANSLATION
```

需要：

- 多 Episode 上传；
- 用户拖动排序；
- Episode order；
- ffprobe；
- decode preflight；
- 损坏视频明确失败。

## 文本项目

适用：

```text
NOVEL_TO_DRAMA
SCRIPT_TO_DRAMA
SCRIPT_LOCALIZATION
```

需要：

- TXT / Markdown；
- 编码检查；
- SourceDocument；
- document revision；
- 替换源文本后下游 Artifact STALE。

P3 暂不进入 ASR / OCR / VLM / H3。
