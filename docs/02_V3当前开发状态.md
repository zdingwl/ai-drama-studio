`SHOT_ANCHORS` 采用项目级聚合 Artifact：每次发布会描述当前 `SOURCE_VIDEO` revision 下已经完成的 Episode ShotBoundarySet，避免多 Episode 互相覆盖正式结果。

## P5 Shot Boundary 检测

当前本地方案：

```text
PySceneDetect AdaptiveDetector
+
暗场 / 淡黑 ThresholdDetector
+
白场 / 闪白 ThresholdDetector
+
候选边界聚类去重
+
极短 Shot 抑制
```

目的：避免只靠单一固定 scene threshold，在短剧常见快速运动、硬切、淡入淡出、闪白中出现大面积误切或漏切。

FFmpeg 负责 thumbnail / Reference Clip 物化和 Reference Clip 完整解码验证。

普通用户界面不展示 detector 参数、FFmpeg 参数、fingerprint 或 ProviderJob。

## P5 页面

