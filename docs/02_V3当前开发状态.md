# 当前 Source Understanding 架构

完整 Episode 永远是 Source Truth：

```text
SOURCE_VIDEO / 完整 Episode
= Source Truth
```

视频类项目内部编排：

```text
完整 Episode
        │
        ↓
Media Preflight
        │
        ├────────────────┬────────────────┐
        ↓                ↓                ↓
Shot Anchors         ASR Evidence      OCR Evidence
        │                │                │
        └────────────┬───┴────────────────┘
                     ↓
              Source Evidence
                     +
               完整 Episode
                     ↓
          整集多模态原片理解 / P7
                     ↓
      SOURCE_BIBLE《源作概览分析》
                     ↓
           Story / Rhythm Skeleton
                     ↓
      带全局知识 + Shot Anchors 做逐镜精细拉片 / P8
```

硬规则：

- Shot Boundary 读取完整 `SOURCE_VIDEO`；
- P6 ASR 读取完整连续音轨，不能按 Shot / Reference Clip 分开识别；
- P6 OCR 扫描完整视频时间轴，Shot Anchors 只能辅助抽帧 / 去重；
- P6 Source Evidence 与 P7 Source Understanding 严格分离；
- P7 必须读取完整 Episode，不允许把每个 Shot 独立丢给模型猜剧情后再拼接；
- P7 对白 / OCR 的文字事实必须引用 CURRENT P6 Evidence；模型不得覆盖 canonical Source Evidence；
- P8 必须读取 CURRENT SOURCE_BIBLE，不允许重新从零猜整集故事。

工程实现切片 P5/P6/P7/P8 不等于普通用户必须逐项点击的业务流程。

# P7 已完成基线

正式输出：

```text
SOURCE_BIBLE《源作概览分析》
├─ 素材基线
├─ 整体分析
├─ 时间化原作剧情
├─ 人物 / 人物关系
├─ 场景
├─ 关键道具
├─ Story / 关键事件
├─ Story Skeleton
├─ Rhythm Skeleton
└─ provenance / revision
```

正式契约：

```text
source-video-understanding@1.1.0
p7-source-bible-v2
SOURCE_BIBLE schema 1.1
grounded-source-truth-v2
```

Grounding：

```text
FACT
INFERENCE
UNKNOWN
```

发布规则：

- FACT / INFERENCE 必须有 CURRENT Evidence 或完整 Episode video range 支持；
- UNKNOWN 不能携带 support，也不能与确定性事实正文同时发布；
- `world_rules` 只能是本片内部 FACT，没有内部世界规则时允许空数组；
- 道具外观事实与剧情作用分开；无法确认剧情作用时必须 `null + UNKNOWN`；
- Provider 和 Service publication 双层 fail-closed；
- Evidence 引用通过短引用映射避免模型抄写长 UUID，但未知引用仍 fail closed；
- P6 Source Evidence 在任何 P7 失败 / 编辑 / Provider 切换中都不被改写。

# P7 真实人工验收

真实样例：

```text
货到付款惩治隔壁大妈-第01集.mp4
约 66 秒
1080x1920
```

真实 Provider：

```text
Volcengine Ark
Doubao Seed 2.1 Pro
```

最终结果已人工确认：

- 故事概述、人物、关系、场景、关键道具、Story / Rhythm 可用；
- 时间化剧情是语义窗口，不冒充 Shot Boundary；
- `128 元`、`结婚八年` 等关键事实能从 canonical Evidence 反查；
- `world_rules` 不再输出社会泛化 / 法律结论；
- 黑色垃圾袋不再被补成“倒垃圾时顺手拿花”等无依据因果；
- SOURCE_BIBLE 用户可读、可编辑、可版本化；
- Evidence 默认折叠但可按需查看；
- 类型 / 世界规则分开显示；
- Provenance 可追溯 Provider / Model / ProviderJob / Prompt / Schema / Skill / Grounding / 上游 Artifact；
- API Key 默认密码遮罩，用户显式点击“显示”后才查看原文。

因此：

```text
P7 = ✅
EPISODE_UNDERSTANDING = AVAILABLE
STORY_RHYTHM = AVAILABLE
```
