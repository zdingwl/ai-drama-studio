# 当前 Source Understanding 架构

完整 Episode 永远是 Source Truth：

```text
SOURCE_VIDEO / 完整 Episode
= Source Truth
```

视频类项目内部编排：

```text
完整 Episode
        │
        ↓
Media Preflight
        │
        ├────────────────┬────────────────┐
        ↓                ↓                ↓
Shot Anchors         ASR Evidence      OCR Evidence
        │                │                │
        └────────────┬───┴────────────────┘
                     ↓
              Source Evidence / P6
                     +
               完整 Episode
                     ↓
          整集多模态原片理解 / P7
                     ↓
      SOURCE_BIBLE / Story / Rhythm
                     +
             Shot Anchors
                     ↓
          逐镜精细拉片 / P8
                     ↓
          SOURCE_SHOT_FACTS
```

硬规则：

- Shot Boundary 读取完整 `SOURCE_VIDEO`；
- P6 ASR 读取完整连续音轨，不能按 Shot / Reference Clip 分开识别；
- P6 OCR 扫描完整视频时间轴，Shot Anchors 只能辅助抽帧 / 去重；
- P6 raw ASR Evidence 必须完整保留；canonical Evidence 只做可追溯的 admission / conservative merge，不允许用 OCR/VLM/P7/P8 静默改写；
- P6 Source Evidence 与 P7 Source Understanding 严格分离；
- P7 必须读取完整 Episode，不允许把每个 Shot 独立丢给模型猜剧情后再拼接；
- P7 对白 / OCR 的文字事实必须引用 CURRENT P6 Evidence；模型不得覆盖 canonical Source Evidence；
- P8 必须读取完整 Episode + CURRENT SOURCE_BIBLE + CURRENT SHOT_ANCHORS + CURRENT P6 canonical Evidence；
- P8 Shot 时间只认 P5；对白正文只认 P6；人物 / 场景 / 道具只能绑定 P7 candidate；
- P8 speaker candidate 绑定具体 canonical utterance，只能选择 CURRENT P7 character candidate 或 null；同文案不等于同一 utterance，禁止按字符串相同传播 speaker；
- P8 不得为了修正 ASR 质量自行重新听写；
- P8 speaker candidate 不是 P9 最终 Speaker Truth。

# P6 当前工程基线：Canonical Evidence v3

历史 P6 v1 曾出现：

```text
50 raw ASR segments
→ 激进相邻合并
→ 8 canonical utterances
```

P6 v2 已通过：

```text
p6-source-evidence-v2
segment-preserving-dialogue-v2
large-v3-turbo
```

并在真实样例中恢复为：

```text
56 raw ASR
→ 56 canonical dialogue
73 canonical OCR
```

v2 成功消除了多人超长 canonical merge。但最终 P8 人工音画检查继续发现片尾 residual：

```text
66.020–66.040  你还真去报警啊
66.040–66.220  你还真去报警啊
```

这两条只有约 20ms / 180ms，却各自包含完整一句中文。它们在 v2 中是两个独立 canonical utterance，因此 P8 speaker v2 正确地没有把较早 Shot #026 的 `周宇` 按相同文本自动复制给它们。

当前 v3 工程契约：

```text
p6-source-evidence-v3
segment-preserving-dialogue-v3
adjacent-duplicate-microsegment-v1
large-v3-turbo
```

v3 策略：

- 完整 Episode 连续 ASR 架构不变；
- v2 的保守 segment boundary / explicit continuation merge 原则不变；
- 新增 canonical admission guard：只有同时满足“近相邻 + normalized text 完全相同 + 文本信息量与持续时间物理上不可信”的 duplicate micro segment 才不进入 canonical；
- 单纯“短”不能删除，单纯“文本重复”也不能删除；
- 一个 duplicate copy 可信、另一个 micro copy 不可信时，只过滤不可信 copy；
- 两个 duplicate copy 都不可信时，两者都只保留 raw Evidence；
- raw `AsrEvidenceSegment` 全部保留，并在 provenance 记录 `canonical_included` / exclusion reason；
- 不使用 OCR / VLM / P7 / P8 文本作为 canonical 修正文；
- 不使用真实样例专用词表或时间戳硬编码。

迁移：

```text
0014_p6_microduplicate_guard_v3
```

迁移后必须使旧 canonical 消费链失效：

```text
SOURCE_VIDEO / SHOT_ANCHORS         保持 CURRENT
旧 SourceEvidenceSet                is_current = false
旧 SOURCE_DIALOGUE                  STALE
旧 SOURCE_BIBLE / Story / Rhythm    STALE
旧 SOURCE_SHOT_FACTS                STALE
受影响 ProjectExecutionPlan         STALE / current pointer cleared
```

历史 revision 保留。
