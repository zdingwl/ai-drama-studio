# P4 Task / ProviderJob / Guardrail ▶ 当前阶段

下一步建立所有重任务和外部模型接入之前必须存在的执行底座：

```text
显式 Command
→ Task
→ queue / worker
→ checkpoint / heartbeat / retry / cancel / resume

外部或计费模型调用
→ 先持久化 ProviderJob
→ 再发起远端请求
```

P4 需要确保：

- GET 永远不能启动重任务；
- Skill 不能绕过 ProviderJob；
- API key 不进入数据库、日志、Artifact 或 Git；
- STALE Artifact 不能被下游消费；
- Task 技术成功不等于业务 Artifact 自动 READY。

P4 完成后，P5 才进入 Shot Boundary / thumbnail / Reference Clip；P6 才进入 ASR / OCR；P7 才开始真实接 Step 3.7 Flash 等整集理解模型。
