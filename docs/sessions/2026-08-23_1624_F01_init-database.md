## init_database() 的业务作用

- 使用 `get_app_data_path()` 的结果定位应用级数据目录；
- 创建应用数据目录；
- 使用固定文件名 `app.db`；
- 通过 Alembic 升级到当前 `head`；
- F01 初始 Migration 只创建 `projects` 一张业务表；
- 重复调用安全；
- 返回 `app.db` 路径。

明确不做：创建具体 Project、创建 Workspace、写 `project.json`、插入项目记录、创建后续 Feature 表。

## 为什么采用 Alembic

没有使用 `Base.metadata.create_all()` 作为第二套建表方式。

原因：数据库从第一版就需要版本历史；首次初始化和以后升级统一走 Migration，避免出现“新装机器用 create_all，老机器用 Alembic”的双重 schema 来源。
