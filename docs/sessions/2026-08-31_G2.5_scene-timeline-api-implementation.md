## Implemented

Ordinary-user read endpoints:

```text
GET /api/episodes/{episode_id}/scene-timeline
GET /api/breakdown-runs/{run_id}/scene-timeline
```

Both return only frozen `scene-timeline-v1`.

GET does not start Qwen, ASR, OCR, VLM or any provider.

Narrative materialization is explicit:

```powershell
python scripts/materialize_breakdown_g2_scene_timeline_v1.py <READY_RUN_ID> --device cuda
```

Artifact:

```text
<episode workspace>/breakdown/<run_id>/scene-timeline/narrative-overlay-v1.json
```

Before persisted Narrative is written/read into the user result, G2.5 rechecks:

```text
Run / Episode / ShotRevision anchors
complete Scene ordinal coverage
Scene source_fingerprint
frozen G2.4 support validation for every claim
persisted claim == G2.4 re-accepted claim
frozen apply_scene_narrative_overlay_v1 gate
```

Primary API never exposes:

```text
support Fxxxx
source_fingerprint
Evidence IDs
cluster keys
LocalSubject DB IDs
confidence/provider/model diagnostics
raw LLM/validator warnings
```

Safe fallback behavior:

```text
missing Narrative artifact -> deterministic Timeline + ordinary-user missing warning
stale/corrupt/untrusted artifact -> deterministic Timeline + ordinary-user fallback warning
READY_WITH_WARNINGS overlay -> accepted claims + deterministic values for rejected fields + one generic user warning
```
