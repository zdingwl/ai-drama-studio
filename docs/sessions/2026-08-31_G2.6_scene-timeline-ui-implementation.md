## What changed

The primary `02 拉片 → 拉片结果` path no longer rebuilds the visible result from the legacy `BreakdownDraftPayload`.

It now consumes frozen G2.5:

```text
GET /api/episodes/{episode_id}/scene-timeline
```

Visible reading order:

```text
Scene navigation
→ readable Scene title
→ story summary
→ Scene environment
→ Scene people
→ Shot cards
   → preview / reference clip
   → visual description
   → people
   → action / performance
   → dialogue
   → props
   → cinematography
   → on-screen text
```

Empty sections are hidden. Scene-local `P1/P2/...` refs are mapped to ordinary display names before rendering. Engineering diagnostics are not rendered.

Only one Shot reference video is mounted at a time; the remaining cards use lazy thumbnails.

The existing task bar remains in place for:

```text
重新拉片本集
按顺序批量拉片
```

The existing `镜头管理` workspace is unchanged.
