# P14 中国环境 IndexTTS-2.5 本地模型部署与 502 诊断

> 日期：2026-09-12  
> 状态：P14 本地运行时补充规范；优先级高于 `docs/35` 中“直接以 Hugging Face model id 启动”的示例。  
> 本文只修运行时部署，不改变 `TTS = PLANNED / TIMING = PLANNED / P14 PASS = NO`。

## 1. 502 的含义

产品页如果显示：

```text
IndexTTS-2.5 服务返回 HTTP 502
```

说明应用后端已经能连接 `127.0.0.1:8092`，但 vLLM-Omni 的模型 stage 没有完成就绪。常见原因包括：

- 启动时在线拉 Hugging Face 模型失败或超时；
- `vllm-omni[indextts2]` 依赖未完整安装；
- CUDA / GPU 初始化失败；
- 显存不足；
- 模型 bundle 不完整；
- 旧的 8092 进程仍占端口。

因此 502 不是 Voice Catalog 问题，也不是前端按钮问题。

## 2. 中国环境部署基线

P14 不再把“运行时临时下载 Hugging Face 模型”作为默认路径。默认流程改为：

```text
ModelScope 预下载完整 IndexTTS-2.5 bundle
-> 本地目录 .models/IndexTTS-2.5
-> vLLM-Omni 只加载本地目录
-> --served-model-name IndexTeam/IndexTTS-2.5
-> /health
-> /v1/models
-> READY
```

`.models/` 已加入 `.gitignore`，模型权重不得提交 Git。

## 3. 下载模型

Linux / WSL：

```bash
pip install -U modelscope
./scripts/download_indextts25_model.sh
```

Windows PowerShell：

```powershell
./scripts/download_indextts25_model.ps1
```

默认写入：

```text
<repo>/.models/IndexTTS-2.5
```

也可以通过 `INDEXTTS_MODEL_DIR`（shell）或 `-ModelDir`（PowerShell）覆盖。

## 4. 安装 vLLM-Omni

按 vLLM-Omni 当前 IndexTTS-2.5 官方 recipe 安装带 IndexTTS frontend 依赖的运行时：

```text
vllm-omni[indextts2]
```

CUDA / 驱动 / PyTorch / vLLM-Omni 必须在实际有 NVIDIA GPU 的 Linux / WSL2 环境中匹配安装。仓库脚本不会自动修改驱动或 CUDA。

## 5. 启动

Linux / WSL：

```bash
./scripts/start_indextts25.sh
```

Windows PowerShell：

```powershell
./scripts/start_indextts25.ps1
```

实际命令等价于：

```bash
vllm serve <local-model-dir> \
  --served-model-name IndexTeam/IndexTTS-2.5 \
  --omni \
  --trust-remote-code \
  --port 8092
```

`--served-model-name` 是必须保留的应用合同：即使底层加载的是本地路径，`GET /v1/models` 仍必须暴露 canonical model id `IndexTeam/IndexTTS-2.5`。

## 6. Readiness

先直接验证运行时：

```bash
curl http://127.0.0.1:8092/health
curl http://127.0.0.1:8092/v1/models
python scripts/check_indextts25.py
```

只有 `/health` 成功并且 `/v1/models` 包含：

```text
IndexTeam/IndexTTS-2.5
```

产品才显示 `IndexTTS-2.5 READY`。

新的 readiness 信息对 HTTP 502 明确解释为：

```text
API 外壳已响应，但 IndexTTS 模型引擎未就绪
```

并在响应类型允许时附带最多 240 字符的运行时错误摘要，避免只显示一个无上下文的 `HTTP 502`。

## 7. 真实验收状态

502 消失、页面 READY 只证明 Provider runtime 可用，不等于 P14 PASS。仍需：

```text
真实 Reference Voice
-> 真实 IndexTTS WAV
-> ffprobe
-> 人工逐句听审
-> ACCEPT TARGET_AUDIO
-> TIMING_PLAN
-> 所有 overflow 处理完毕
-> 用户明确 P14 PASS
```

在此之前继续保持：

```text
TTS = PLANNED
TIMING = PLANNED
P14 PASS = NO
```
