# 1. 当前技术目标

Workflow V2 必须保证：

```text
一个正式源事实入口：SourceDramaSnapshot
一个正式工作流状态入口：ProjectFlowState
两个独立原片正式输出视角：Source Script + Source Directing Reference
显式命令启动重推理
GET/read 无副作用
版本变化可追踪
下游过期可判断
内容不确定自动决策
真正技术失败才阻塞
用户发现错误后可追溯修改
```

# 2. 原片理解 Provider 架构

业务层不能直接依赖某个模型实现。

```text
Source Understanding Business
  │
  ├─ SourceVideoUnderstandingProvider
  │    └─ Qwen38VideoUnderstandingProvider
  │         model: Qwen3.8-27B
  │
  ├─ SourceDialogueAttributionProvider
  │    └─ DOrcaDialogueAttributionProvider
  │         model: D-ORCA 8B
  │
  ├─ SourceDialogueEvidenceProvider
  │    ├─ ASR
  │    └─ OCR / Subtitle
  │
  └─ SourceIdentityProvider
       └─ Character V10.1
```

未来增加 FilmOps / ACaM 等专项模型时：

```text
SourceDirectingProvider
  ├─ generic Qwen3.8 directing facts
  └─ optional FilmOps / ACaM enhancement
```

不得改变下游正式数据契约。

# 3. Qwen3.8-27B 契约

## 3.1 输入

- 当前 Episode/Shot revision；
- Reference Clip 或当前 Shot 视频窗口；
- 按策略采样的视频帧；
- Shot 前后文；
- 可选整集/Scene 上下文；
- source language；
- 允许引用的已有 source facts。

## 3.2 输出范围

至少覆盖：

- visual_description；
- subjects；
- actions；
- expressions；
- posture；
- gaze；
- interactions；
- blocking；
- scene/location/environment；
- props；
- shot_type；
- camera_angle；
- composition；
- camera_motion；
- lighting；
- continuity；
- narrative_function；
- cross-shot event understanding。

Qwen3.8 不得成为 canonical source dialogue 的唯一来源，也不得覆盖 ASR/OCR 原始记录。

## 3.3 结构要求

Provider 输出必须：

- schema-valid；
- 时间范围落在当前 source revision 内；
- source refs 可追溯；
- 不产生 TargetCharacter / target dialogue 等下游数据；
- 保存 provider/model profile 和 input fingerprint。

# 4. D-ORCA 8B 契约

## 4.1 目标

D-ORCA 负责解决：

```text
WHEN：什么时候说
WHO：谁说
WHAT：说了什么（作为校验/辅助证据）
```

其中项目最核心使用的是 **WHO / Speaker Attribution**。

## 4.2 输入

- 当前 Episode/Shot 对应视频片段；
- 原始音轨；
- source timebase；
- 可见人物/track/identity evidence；
- 可选 ASR utterance candidates。

## 4.3 输出

建议内部持久化为版本化的 `SourceDialogueAttributionArtifact`，至少包含：

```text
artifact_id
provider = D_ORCA
model_profile
source_revision
input_fingerprint
utterance_candidates[]
  start_us
  end_us
  transcript_evidence
  speaker_visual_ref / speaker_track_ref
  speaker_score
  temporal_score
  provenance
```

该 artifact 是**证据层**，不是最终 SourceDialogueUtterance 本体。

## 4.4 Speaker 正式化

```text
D-ORCA attribution
  ↓
visual ref / track ref
  ↓
Character V10.1 identity normalization
  ↓
DialogueSpeakerBinding
```

优先级：

1. 用户已有 current manual speaker override；
2. D-ORCA + Character V10.1 得到唯一正式 source identity；
3. 已有明确 `SPEAKER` relation；
4. 当前规则式 `source_dialogue_speaker_resolver_v1`；
5. best-effort source identity / OFFSCREEN / UNKNOWN。

规则式 resolver 从“主要推断器”降为 fallback。

# 5. ASR / OCR / Source Dialogue 契约

## 5.1 原始 evidence 不可变

- 原始 ASR sidecar 不就地修改；
- 原始 OCR / subtitle evidence 不就地修改；
- D-ORCA transcript 不覆盖原始 ASR；
- 用户修改形成正式 revision/decision layer。

## 5.2 完整对白是业务对象

```text
SourceDialogueUtterance
      ↓ 1:N
ShotDialogueProjection
```

一条完整对白跨多个 Shot：

- source_text 只保存一次；
- source_start_us/source_end_us 只保存一次；
- Shot 只保存 projection；
- 所有投影共享一个 dialogue_group_id / utterance_id。

## 5.3 canonical text 自动选择

自动 reconciliation 可以使用：

- ASR confidence；
- OCR/subtitle 稳定性；
- 时间重合；
- source language；
- D-ORCA WHAT evidence；
- 上下文一致性。

结果保存：

```text
source_text
text_resolution_method
text_confidence
provenance
```

低 confidence 不阻塞；完全没有可支持的语音/字幕证据时不凭空造对白。

# 6. Character V10.1 契约

至少保持层级：

```text
Detection / Face
Track
Scene-local Person / LocalSubject
Identity Evidence
Final Character / Provisional Source Character
TargetCharacter
```

规则：

- Track / Face / LocalSubject 不直接当正式人物；
- 不降低跨镜错误合并阈值；
- 证据不足时宁可保留多个 provisional identity；
- provisional identity 必须有稳定 source key，可供后续自动流程引用；
- 用户后续合并/拆分时形成 AssetRevision 并使下游 STALE。

# 7. SourceDramaSnapshot 唯一事实边界

```text
ASR / OCR / Qwen3.8 / D-ORCA / Tracking / Character / Scene / Prop
                              ↓
                     SourceDramaSnapshot
                              ↓
                     模块 6—10
```

下游禁止绕过 Snapshot 直接拼：

- raw ASR；
- raw OCR；
- D-ORCA raw artifact；
- Track ID；
- LocalSubject；
- Qwen raw response；
- 未版本化临时文件。

Snapshot 至少包含：

- Project / Episode；
- Scene；
- Shot；
- Reference Clip；
- SourceDialogueUtterance；
- ShotDialogueProjection；
- Final/Provisional Source Character；
- Final Scene / Prop；
- Shot Asset Binding；
- Dialogue Speaker Binding；
- Source Directing Facts；
- source revision；
- source fingerprint；
- provenance references。

Snapshot 不得包含 Target-side 数据。

# 8. Source Script 与 Source Directing Reference

二者都派生自同一个 current SourceDramaSnapshot。

## 8.1 Source Script

面向用户可读剧本：

- Scene heading；
- 剧情动作；
- 人物关系；
- canonical dialogue；
- Speaker。

现有 `source_screenplay_runtime_v2.py` 的硬规则继续保持：

- SourceDramaSnapshot 不可变；
- 模型只组织/合并 grounded ACTION；
- canonical dialogue 正文不由剧本模型生成；
- 每条 canonical dialogue exact-once；
- GET 只读取 materialized artifact；
- compile 必须显式 POST/task。

## 8.2 Source Directing Reference

面向 Target Storyboard / H3：

- source shot times；
- Reference Clip；
- action/performance；
- blocking；
- shot type；
- camera angle；
- camera motion；
- composition；
- lighting；
- props；
- continuity。

剧本模型可以省略这些技术字段以保持可读性，但数据本身不能丢。

# 9. 自动决策状态模型

## 9.1 Validity

| 状态 | 含义 |
|---|---|
| NOT_BUILT | 尚未生成 |
| CURRENT | 对应当前上游 |
| STALE | 上游变化，需要显式重算 |

## 9.2 Execution

| 状态 | 含义 |
|---|---|
| IDLE | 空闲 |
| QUEUED | 等待执行 |
| PROCESSING | 执行中 |
| SUCCEEDED | 本次任务技术完成 |
| FAILED | 技术失败 |
| INTERRUPTED | 中断，可恢复 |

## 9.3 Readiness

新语义：

| 状态 | 含义 |
|---|---|
| READY | 当前结果可下游消费 |
| READY_WITH_WARNINGS | 可消费，但存在低置信度/自动决策提示 |
| BLOCKED_DEPENDENCY | 缺少上游结构数据 |
| WAITING_RUNTIME | 模型/Worker/运行环境不可用 |
| BLOCKED_TECHNICAL | 文件/schema/结构失败，不能形成可消费数据 |

### legacy `BLOCKED_REVIEW`

现有代码可以暂时保留枚举兼容，但迁移完成后：

- 普通人物身份不确定；
- 普通 Speaker 不确定；
- 普通对白差异；
- 场景/动作描述不确定；

**不得再产生 `BLOCKED_REVIEW` 作为主流程门禁。**

历史 ReviewIssue 可以继续显示为 legacy/correction item，但 `consumable` 不再由它们的数量直接决定。

# 10. Auto Resolution Metadata

所有自动决策建议统一保留：

```text
resolution_state = AUTO_RESOLVED | EXPLICIT | MANUAL_OVERRIDE | OFFSCREEN | UNKNOWN
resolution_method
confidence
provider_refs[]
source_revision
resolved_at
```

这些字段用于：

- 调试；
- 用户纠错；
- A/B 模型验收；
- 重新计算；
- 判断 D-ORCA/Qwen3.8 是否真正改善结果。

普通用户界面默认隐藏。

---

# 11. Review / Correction 兼容规范

现有 ReviewCase / ReviewIssue / Speaker Review / 人物确认能力暂不删除。

新定位：

```text
历史兼容
+
用户主动纠错
+
高级诊断
```

不再是：

```text
AI 不够确定
→ 强制用户逐项确认
→ 才能进入 Snapshot/下游
```

### 用户修改正确顺序

```text
用户提交正式修改
→ 写业务 revision / override
→ 重新 Validator
→ source fingerprint 改变
→ 下游 STALE
→ 用户显式重算或继续自动流程
```

禁止只关闭提醒而不写正式业务对象。

# 12. 真正阻塞的错误分类

## Technical / Runtime

- VIDEO_UNREADABLE；
- VIDEO_DECODE_FAILED；
- AUDIO_REQUIRED_BUT_UNAVAILABLE；
- QWEN38_RUNTIME_OFFLINE；
- DORCA_RUNTIME_OFFLINE；
- MODEL_OUTPUT_INVALID；
- ARTIFACT_CORRUPTED；
- H3_RUNTIME_OFFLINE；
- TTS_RUNTIME_OFFLINE；
- LIPSYNC_RUNTIME_OFFLINE。

## Structural

- 非法时间范围；
- duplicate/current pointer 冲突；
- utterance/projection 引用损坏；
- required asset 不存在；
- final MP4 无法完整解码。

内容语义低 confidence 不属于上述阻塞。

# 13. Revision / Fingerprint

上游变化时：

1. 旧结果保留历史；
2. old current 标记 STALE/SUPERSEDED；
3. 清 current pointer；
4. 计算影响范围；
5. 页面显示需要重算；
6. 只有显式命令启动重任务。

最低失效矩阵：

| 上游变化 | 至少失效 |
|---|---|
| 替换原视频 | 模块 2—10 |
| Shot 边界变化 | 模块 3—10 |
| Qwen3.8 理解结果变化 | 模块 4—10 |
| D-ORCA attribution 变化 | Speaker Binding / Snapshot / 模块 6—10 |
| Character identity 变化 | Snapshot / 模块 6—10 |
| SourceDramaSnapshot 变化 | 模块 6—10 |
| Source/Target Script 变化 | 对应 Target assets / 模块 8—10 |
| TargetCharacter/Scene/Voice 变化 | 模块 8—10 |
| TargetDialogue/TTS 变化 | Timeline / 模块 9—10 |
| Storyboard/Timeline/Segment 变化 | 模块 9—10 |
| GenerationSelection 变化 | 模块 10 |

# 14. GET / POST 硬边界

## GET 必须纯读取

GET 不得：

- 创建 Task；
- 下载模型；
- 启动 Qwen3.8；
- 启动 D-ORCA；
- 启动 ASR/OCR；
- 自动写人物绑定；
- 自动关闭 Review；
- 自动编译缺失 artifact。

## 重推理必须显式命令

例如：

```text
POST .../breakdown
POST .../source-understanding/compile
POST .../source-screenplay/compile
POST .../target-script/compile
POST .../h3-generate
```

所有重任务至少携带：

- Idempotency-Key；
- expected workflow revision；
- input fingerprint；
- Episode/Shot processing scope；
- action source。

---

# 15. Task Receipt

每个重任务持久化：

- task_id；
- task_type；
- provider/model profile；
- input fingerprint；
- status；
- checkpoint；
- current/total（准确时）；
- heartbeat；
- retry_count/max_retries；
- last_error；
- timestamps。

任务规则：

- 页面 mount 不创建；
- refresh 不创建；
- route change 不创建；
- task finished 不隐式创建下一项 GPU 任务；
- 相同命令幂等；
- 当前成功 checkpoint 尽量复用；
- 模型格式错误有限自动重试；
- Runtime 恢复后显示可重试，不偷偷重跑。

# 19. H3 Provider 与 QC

```text
GenerationSegment
→ VideoGenerationProvider
→ MiniMaxH3Provider
→ H3RuntimeManager
→ Local MiniMax H3
```

GenerationAttempt 是不可变执行历史。

必须保持：

```text
Attempt
→ structural QC
→ semantic QC
→ limited retry
→ GenerationSelection
```

只有 GenerationSelection 可进入后期。

硬解码失败不能被“人工忽略”绕过。

# 20. 后期安全规范

唯一视频输入：

```text
GenerationSelection
→ PostProductionSegment
→ EpisodeOutput
```

多人 lip-sync：

```text
Target Speaker
→ 目标人物身份定位
→ ROI
→ LatentSync
```

Target Speaker 可以是自动决定，不要求人工确认。

原音频规则：

```text
raw source audio 永远不能直接混入目标成片
```

背景音处理失败可以安全降级：

```text
TARGET_DIALOGUE_ONLY_FALLBACK
```
