# P5 视频技术预处理

适用：REPLICA / REDRAW / TRANSLATION。

## 流程

```text
Episode
→ media preflight
→ source timebase
→ Shot Boundary
→ Reference Clip
```

## 注意

Shot Boundary 只负责时间锚点，不做剧情理解。

## 输出

- [ ] ShotAnchor；
- [ ] source_start_us；
- [ ] source_end_us；
- [ ] thumbnail；
- [ ] reference_clip；
- [ ] detector profile；
- [ ] revision/fingerprint。

## 验收

- [ ] Shot 不重叠；
- [ ] Shot 顺序正确；
- [ ] Reference Clip 可完整 decode；
- [ ] 人工改边界后下游 STALE。

# P6 ASR / OCR / Source Dialogue

## 输出

- [ ] ASR evidence；
- [ ] OCR evidence；
- [ ] SourceDialogueUtterance；
- [ ] ShotDialogueProjection 1:N；


## 验收

- [ ] projection 时间 offset 正确；
- [ ] raw ASR/OCR immutable；
- [ ] 没证据时不凭空写对白。

# P7 整集理解 / Source Bible

## 输入

- [ ] key_events；
- [ ] script_scene structure；

## 硬规则

- [ ] 不改 canonical dialogue；
- [ ] character candidate 不是 Final Character；
- [ ] ShotAnchor 只是时间锚点；

- [ ] 外部调用走 ProviderJob。

## 验收

- [ ] 真实完整 Episode 跑通；

- [ ] 故事时间线正确；
- [ ] 关键剧情没有明显漏掉；

# 开发纪律

每完成一个 P 阶段，都必须报告：

```text
代码实现：YES/NO
自动测试：YES/NO
前端真实操作：YES/NO/不适用
模型真实运行：YES/NO/不适用
真实素材验收：YES/NO/不适用
用户看听验收：YES/NO/不适用
```

禁止用“代码写完”代替“真实能力跑通”。
