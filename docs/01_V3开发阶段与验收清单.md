# P2 Project + Skill Kernel ▶ 当前下一阶段

P2 不再实现“六套固定 stage graph”。

P2 的目标是建立：

```text
Project Type
→ Root Skill
→ Plan Compiler
→ ProjectExecutionPlan
→ Artifact Graph 基础
```

## P2.1 Project

- [ ] `Project` model；
- [ ] `ProjectType` 六枚举；
- [ ] source_language；
- [ ] target_language；
- [ ] target_region；
- [ ] scene_strategy；
- [ ] audio_policy；
- [ ] visual_style；
- [ ] root_skill_id；
- [ ] root_skill_version；
- [ ] workflow_revision；
- [ ] UTC timestamps；
- [ ] Alembic migration。

六种类型：

```text
REPLICA
REDRAW
TRANSLATION
NOVEL_TO_DRAMA
SCRIPT_TO_DRAMA
SCRIPT_LOCALIZATION
```

V3 不兼容旧数据库，不提供 legacy 默认 project_type。

## P2.2 Skill Definition / Registry

- [ ] `SkillDefinition` 数据契约；
- [ ] `SkillManifest` schema；
- [ ] `SkillRegistry`；
- [ ] Skill version；
- [ ] Skill category；
- [ ] when_to_use / when_not_to_use；
- [ ] required_inputs；
- [ ] readable_artifacts；
- [ ] required_capabilities；
- [ ] subskills；
- [ ] output_contracts；
- [ ] completion_criteria；
- [ ] failure_policy。

首版 Skill 正文保存在仓库：

```text
skills/projects/*/SKILL.md
```

机器执行必须读取结构化 manifest，不靠正则解析 Markdown。

## P2.3 六个 Root Project Skill

- [ ] `replica`；
- [ ] `redraw`；
- [ ] `translation`；
- [ ] `novel_to_drama`；

- [ ] plan revision；
- [ ] plan input fingerprint；
- [ ] root skill version；
- [ ] required capability；
- [ ] dependencies；
- [ ] expected outputs；
- [ ] current plan pointer。

## P2.7 Plan Compiler

首版必须先可测试、可重复。

- [ ] 根据 `project_type + root skill + 当前 artifact` 编译计划；
- [ ] 同样输入得到同样 Plan；
- [ ] 不需要的能力不创建假完成步骤；
- [ ] 用户配置变化后可以显式 compile 新 Plan；
- [ ] GET 不自动 compile；
- [ ] Plan 持久化后页面刷新不改变。

P2 的 Plan Compiler 可以是确定性实现。

后续 AgentReasoningProvider 可以增强规划，但不能破坏上述确定性边界。

## P2.9 前端

- [ ] 项目卡展示项目类型；
- [ ] 工作区读取后端 Plan；
- [ ] 前端不维护独立 stage graph；
- [ ] P2 用简单列表展示 Plan，不做无限画布。

## P2 必测

- [ ] 六个 ProjectType 都能持久化；
- [ ] 六个 Root Skill 都能加载；
- [ ] ProjectType 与 Root Skill 映射正确；
- [ ] 非法枚举 422；
- [ ] Skill manifest schema 错误 fail-fast；
- [ ] 同输入 Plan 稳定；
- [ ] 不同 ProjectType Plan 不同；
- [ ] GET 不写库；
- [ ] GET 不执行 Agent / Provider；
- [ ] Plan compile 是显式 command；
- [ ] ArtifactRelation 不允许引用不存在 Artifact；
- [ ] source / target namespace 不被混写。

## P2 完成条件

用户可以创建六种项目，后端真正绑定对应 Root Skill，并生成可持久化的当前执行计划。

这时**不代表六种业务能力已实现**；未实现 capability 必须显示“尚未接入 / 等待后续阶段”，不能伪造成功。
